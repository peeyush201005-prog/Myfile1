# Birthday Surprise Landing Page

A responsive, animated birthday page. Visitors enter their name and birth date to unlock the surprise.

## Features
- Name + birth date form with validation (saved in the browser with `localStorage`)
- Personalized greeting and live countdown to the visitor's next birthday
- Blow-out candle cake, wish picker, panda-catching game, balloon-popping game
- Realistic cake cutting: knife slices a layered cake and serves the first slice
- Thank-you popup with rising balloons and a hug button (emoji burst, squeeze effect, vibration)
- Accessible labels, focus styles, and reduced-motion support

## Files
- `index.html` - page structure and content
- `css/style.css` - design, layout, and animations
- `js/main.js` - form, countdown, games, cake cutting, confetti, popup and hug effect

## Run it
Open `index.html` in a browser. No build step or backend is needed.
